# OpenKFZ 🚗

OpenKFZ is an open-source vehicle management platform.

The goal of OpenKFZ is to provide a modern, transparent and extensible solution for managing vehicle-related information.

## Features

* 🚘 Vehicle management
* 📄 Structured vehicle data
* 🔍 OCR and document processing support
* 🗄️ Database integration
* 🌐 Modular architecture

## Tech Stack

* Kotlin
* Android
* Jetpack Compose
* Gradle
* GitHub Actions

## Build

Clone the repository:

```bash
git clone https://github.com/NeoShinobiDev/OpenKFZ.git
cd OpenKFZ
```

Build the project:

```bash
./gradlew assemble
```

Run a full build:

```bash
./gradlew build
```
