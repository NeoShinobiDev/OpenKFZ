Security Policy
Reporting Security Issues

If you discover a security vulnerability in OpenKFZ, please report it responsibly.

Please do not create a public GitHub issue for security vulnerabilities.

Instead, contact the project maintainers privately and provide:

A description of the vulnerability
Steps to reproduce the issue
Potential impact
Any relevant logs or screenshots
Supported Versions

Security fixes are provided for the latest development version and supported releases.

Version	Supported
Latest	Yes
Older releases	Best effort
Response Process

After receiving a security report:

The issue will be reviewed
The vulnerability will be investigated
A fix will be prepared if necessary
A release or update will be published

We appreciate responsible disclosure and thank security researchers who help improve OpenKFZ.
