Contributing to OpenKFZ

Thank you for your interest in contributing to OpenKFZ!

OpenKFZ is an open-source vehicle management platform and welcomes contributions from developers, testers, documentation writers and enthusiasts.

How to contribute

There are several ways you can help:

Report bugs
Suggest new features
Improve documentation
Submit code changes
Review pull requests
Reporting bugs

Before opening a bug report:

Check if the issue already exists
Make sure you are using the latest version
Provide as much information as possible

Please include:

Description of the problem
Steps to reproduce
Expected behavior
Actual behavior
Device and operating system information
Relevant logs or screenshots
Feature requests

Feature ideas are welcome.

Please explain:

What problem the feature solves
How it should work
Why it would improve OpenKFZ
Development setup

Requirements:

Git
Android Studio or another Kotlin-compatible IDE
JDK 17+
Android SDK

Clone the repository:

git clone https://github.com/NeoShinobiDev/OpenKFZ.git
cd OpenKFZ

Build the project:

./gradlew build

Run checks:

./gradlew lint

Branch workflow

Create a separate branch for your changes:

git checkout -b feature/my-feature

or:

git checkout -b fix/my-bugfix

Keep commits clear and descriptive.

Examples:

Add vehicle database model
Fix crash when loading vehicles
Improve README documentation

Pull requests

Before submitting a pull request:

Make sure the project builds successfully
Run tests and lint checks
Update documentation if needed
Explain what your changes do

Pull requests should be focused on one topic.

Code style

Please follow the existing Kotlin style:

Use meaningful names
Keep functions small
Avoid unnecessary complexity
Add comments where logic is not obvious
