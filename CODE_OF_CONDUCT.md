Code of Conduct
Our Commitment

We are committed to providing a welcoming, respectful and inclusive environment for everyone contributing to OpenKFZ.

All contributors are expected to act professionally and respectfully.

Expected Behavior

Contributors should:

Be respectful and constructive
Welcome different opinions and experiences
Give helpful feedback
Focus on improving the project
Unacceptable Behavior

The following behavior is not tolerated:

Harassment or discrimination
Personal attacks
Trolling or deliberately disruptive behavior
Publishing private information without permission
Reporting Issues

If you experience or witness unacceptable behavior, please report it to the project maintainers.

Scope

This Code of Conduct applies to all project spaces, including:

GitHub issues
Pull requests
Discussions
Other OpenKFZ community spaces
Enforcement

Project maintainers may remove, edit or reject contributions that violate this Code of Conduct.

Thank you for helping make OpenKFZ a respectful open-source project.
